# SF-001

## Contextual Intelligence

Mission

Stop Searching.

Start Playing.

Vision

Oracle proactively delivers the right public gaming intelligence at exactly the right moment.

The Operator should no longer need to interrupt gameplay to search YouTube, Google or forums.

Oracle should instead surface useful intelligence naturally.

Examples

- Secret bunker codes
- Easter Egg progression
- Hidden collectibles
- Mission objectives
- Rare vehicle locations
- Hidden loot
- Interactive map intelligence
- Exploration guidance

Principles

Oracle provides guidance.

Oracle never automates gameplay.

Oracle never reads protected game memory.

Oracle never provides unfair competitive advantages.

Oracle should always respect the rules of supported games.

# Purpose

This document defines the technical architecture for Project Meta and Oracle.

Oracle is not a single-page AI tool.

Oracle is the first product inside Project Meta: an AI-powered gaming performance platform designed to help players improve, remember their progress, and evolve over time.

---

# Core Principle

Everything revolves around one object:

## Oracle Session

An Oracle Session can represent:

- A text-based fight analysis
- A video clip analysis
- A loadout recommendation
- A GTA VI map route
- A coaching plan
- A future squad review

Every feature either creates, reads, analyses, or improves an Oracle Session.

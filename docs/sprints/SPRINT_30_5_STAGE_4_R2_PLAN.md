## Objective

## Architecture

The qualification host runs the disposable local Supabase topology. The exact R6
certificate is admitted temporarily to LocalMachine TrustedPeople, the accepted
MSIX is installed, and the package receives an attempt-scoped create-only LocalState
configuration through the R12 contract. `IApplicationActivationManager` activates
the package. An Oracle loopback origin is admitted only when its listener belongs to
the ownership-verified installed-package process tree and `/auth` responds
affirmatively. The unchanged ten journeys then execute against that origin.

The browser receives only public provider configuration. Provider service material
and the Web session secret remain restricted to the packaged server and are
prohibited from renderer output, logs and evidence. Production endpoints, email,
data, signing, publication and deployment are prohibited.

## Governed lifecycle

The prepared lifecycle has 20 ordered phases: authority consumption; baseline and
zero-state verification; provider admission; temporary trust; exact installation;
runtime-configuration creation; direct activation; installed-server admission; the
ten journey results grouped into authentication, rendering, isolation and session
phases; exact package/trust/provider teardown; zero-residue cleanup; and create-only
evidence freeze.

Any failed pre-authority gate stops before authority. Any post-consumption failure
stops forward execution, preserves the original failure and permits only bounded
teardown. A consumed authority cannot be retried.

## Preparation boundary

The preparation contract records all execution-authority booleans as false. Neither
the validator nor either development rehearsal can create authority, attempt or
qualification evidence. Qualification remains barred until a separate Founder
mission binds a reviewed preparation commit/tree, fresh preflight record and one
execution token.

## Preserved unavailable evidence

`installationMediaEvidencePresent` remains `false`.

The Founder accepts the assertion that Windows was clean-installed using
Microsoft's official Media Creation Tool USB workflow, but the original USB
or ISO hash was not retained.

Oracle cannot cryptographically prove the identity of the original
installation media. It instead proves the observed freshness, integrity and
uncontaminated state of the resulting Windows installation.

## Invalidation

The admission is host-specific, installation-specific and non-transferable.
It is invalidated by:

- Windows reinstall or reset;
- system-disk replacement;
- system-image restoration;
- Secure Boot change;
- TPM change;
- contamination;
- unexplained software; or
- failed integrity controls.

Invalidation returns the host to admission review. It does not permit evidence
rewriting or inference.

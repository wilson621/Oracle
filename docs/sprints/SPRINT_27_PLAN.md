# SPRINT 27 PLAN — CONTEXTUAL COMPANION AND REFERENCE INTEGRATION

**Status:** Founder-approved; source complete and source-certified; exact live
observation profile remains provisionally certified pending workstation test
**Architecture:** ADR-031, ADR-032, ADR-040, ADR-041, ADR-042, ADR-043,
ADR-044 and ADR-045
**Reference profile:** Minecraft: Java Edition 26.1.1, Windows, English (US),
Founder-controlled single-player
**Deployment:** Not authorised

## Objective

Prove Oracle's Game Integration and Companion architecture against a second,
materially different game using one external, local, ephemeral and
spoiler-controlled advancement/discovery journey.

## Scope

1. Immutable versioned compatibility-certificate contract with `certified`,
   `provisionally-certified`, `expired` and `revoked` states.
2. Per-capability fail-closed eligibility and 90-day maximum review interval.
3. Minecraft: Java Edition 26.1.1 Windows detection and exact-profile
   compatibility enforcement.
4. Explicit transient observation consent, visible indicator, pause and revoke.
5. Attached-window-only local capture with versioned allowlisted regions.
6. Zero raw-frame retention, upload, serialization, logging or renderer
   projection.
7. Immutable confidence-bearing transient derived observations.
8. One original text-only diamond advancement/discovery Guidance package with
   progressive spoiler levels.
9. Session-scoped non-authoritative transient journey progress.
10. Detach, target change, process loss, certificate change, stale work and
    recovery invalidation.
11. Renderer-safe observation state and bounded controls only.
12. Common Game Integration compatibility and observation conformance suite.
13. Canonical Web/Electron manifest 1.6.0 exact equality if Minecraft
    integration/provider composition is added.
14. Local certification evidence and documentation reconciliation.

## Pinned certification assumptions

- operating system: Windows;
- edition/version: Minecraft: Java Edition 26.1.1;
- executable family: official launcher-provided Java runtime;
- player mode: Founder-controlled single-player only;
- locale: English (United States);
- display: windowed or borderless-windowed;
- minimum attached content bounds: 1280 by 720;
- approved GUI scale: 3;
- observation processing: local deterministic recognizer;
- capture source: attached window only;
- knowledge: original Oracle-authored text only; and
- progress: memory-only for the active coordinator instance.

Any mismatch is unsupported and fails closed.

## Implementation phases

### Phase 1 — Governance and contracts

- ADR-044 and ADR-045;
- certificate, profile, lifecycle and capability contracts;
- validation, expiry, provisional and revocation policy; and
- focused lifecycle verification.

### Phase 2 — Minecraft extension

- detection profile and Game Integration;
- initial immutable certificate;
- original curated Guidance package;
- diamond journey Context and progress projection; and
- registry/composition integration.

### Phase 3 — Ephemeral observation

- local attached-window capture adapter;
- consent and capture-state coordinator;
- allowlisted region enforcement;
- frame-lifetime disposal;
- bounded local recognition;
- confidence, freshness and stale-result controls; and
- detach/recovery invalidation.

### Phase 4 — Presentation and certification

- renderer-safe observation indicator and controls;
- manifest 1.6.0 exact equality;
- end-to-end synthetic and local adapter certification;
- complete regression verification; and
- implementation, certification, evidence and living-document reconciliation.

## Exclusions

No deployment, migration, persistence, retained frame/screenshot/clip,
retained observation/Guidance/progress, upload, external processing,
multiplayer, Realms, servers, mods, add-ons, plugins, APIs, AI Guidance,
automated input, authoritative mutation, Gate C, Guidance v2, Desktop Platform
API v2, wider Minecraft claim or External Companion boundary change is
authorised.

## Exit criteria

The exact approved profile alone can become eligible through a current
certificate. Consent is explicit and resets on recovery. Capture never leaves
the main-process observation operation. Raw data is disposed after local
recognition. Uncertainty, expiry, revocation, profile mismatch, detach and stale
work remove affected capability before presentation. The one bounded journey
produces validated transient Guidance and progress without authoritative
mutation. All focused and complete verification passes.

# ORACLE SPRINT 24 ENGINEERING PLAN

**Sprint:** 24 — Adaptive Coaching, Planner and Progression
**Authority:** Founder-approved under ADR-042
**Owner:** Oracle Platform Engineering
**Status:** Implemented and locally certified; awaiting Founder acceptance
**Activated:** 24 July 2026
**Production:** No deployment, migration execution or persistence activation

## Objective

Carry one evidence-bound Session recommendation through coaching, a measurable
Mission, planning, later Session Evidence, exactly-once progression and
correlational reassessment.

## Invariants

- ADR-042 ownership is exclusive.
- Progression is earned only from verified admitted Evidence.
- AI, clients, renderers and models cannot award progression.
- Session and report authorities remain unchanged.
- Every identity is stable; every mutation is authenticated, idempotent and
  concurrency-safe.
- Game semantics remain in Game Integrations.
- Causal coaching claims are prohibited.
- Manifest/runtime equality remains mechanical.
- Persistence remains inactive.

## Phases

1. Versioned coaching, Mission, Planner, progression and correlation contracts.
2. Authoritative AI Coach, Mission, Planner and Progression Services.
3. Migration 014 implementation and disposable PostgreSQL certification.
4. Manifest and Application reconciliation; legacy authority removal.
5. End-to-end, security, replay, concurrency, deletion and regression
   certification.

## Definition of done

A known report recommendation deterministically produces one measurable
Mission and Planner projection. Only verified later Session Evidence can
complete it. Exact replay and concurrency produce one completion, one XP
transaction and one instance of each eligible Achievement. The outcome is
reassessed as correlation with evidence and confidence. No renderer-safe output
contains private source records or mutation capability.

## Exclusions

No deployment, Migration 014 execution in production, Gate C, persistence
activation, persisted producer/consumer activation, production change,
External Companion boundary change or weakening of ADR-040 through ADR-042.

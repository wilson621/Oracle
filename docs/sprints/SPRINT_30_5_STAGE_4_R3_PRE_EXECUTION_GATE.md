# Sprint 30.5 Stage 4 Requalification R3 Pre-Execution Gate

**Status:** Engineering preparation passed; authority not created
**Classification:** Pre-authority governance record
**Last Reviewed:** 4 August 2026

The Founder has authorised one complete R3 mission, but the committed preparation
baseline cannot create a transfer, authority or attempt. The execution-enabled
overlay must first bind the reviewed preparation commit/tree and manifest, encode a
new single-use execution token, enable one create-only transfer, and permit at most
one governed attempt.

Before authority creation, the transferred payload must pass exact manifest and
custody verification, independent complete-inventory verification, approved-host
continuity, Administrator admission, exact tool and image checks, reparse-free path
checks, fresh zero state, create-only authority/evidence/return roots, security and
trust checks, and absence of every active IPv4 or IPv6 default route.

The pre-authority record must be fresh and hash-bound to the new R3 grant, transfer,
candidate, execution contract and return root. The executor must recheck all facts
before consuming authority. The harness verifies network isolation but never changes
network configuration.

Only one authority and one attempt may exist. Any post-consumption failure is
permanent for that identity; bounded teardown must preserve the original failure and
no retry is permitted. R2 identities and evidence namespaces are permanently
ineligible for reuse.

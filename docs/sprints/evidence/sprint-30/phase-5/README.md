# Sprint 30 Phase 5 Evidence

This directory binds the final integrated local qualification to the accepted
Phase 4 baseline and the corrected frozen candidate.

- `generated/qualification-candidate.json` binds source, dependencies,
  migrations, manifests, environment and authority.
- `generated/quality-contract.json` records final deterministic Guidance and
  source accessibility checks.
- `generated/web-performance.json` records final current-host startup, route
  boundary, API boundary, CPU and memory results.
- `generated/supply-chain.json` records the development-tool advisory,
  correction and zero-vulnerability rerun.
- `generated/integrated-matrix.json` records every qualification domain and
  its passed, deferred or unavailable state.
- `generated/integrated-verification.json` is the mechanical candidate and
  dossier consistency result.

deployment, migration, persistence, signing, publication, distribution or
push was used.

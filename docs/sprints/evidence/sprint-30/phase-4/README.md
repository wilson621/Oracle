# Sprint 30 Phase 4 Evidence

This directory contains local, reproducible performance, accessibility,
compatibility and support qualification evidence.

- `generated/quality-contract.json` records source accessibility foundations,
  deterministic Guidance latency and authority boundaries.
- `generated/web-performance.json` records production-build startup, canonical
  route, bounded API, CPU and memory measurements.
- `generated/browser-accessibility.json` records the rendered Web review at
  desktop, compact and scalable-text configurations.
- `generated/verification-summary.json` records final Phase 4 command results
  and repository state.

GPU measurement in an installed package, live Supabase Auth and disposable
clean-Windows certification remain unavailable or deferred and are never
represented as passed. No production endpoint, credential, diagnostics
provider, upload, retention, signing, publication, distribution, deployment or
push is used.

# Sprint 30.5 Stage 2 Requalification R4 Implementation

Status: **FOUNDER-ACCEPTED AND FORMALLY CLOSED**

R4 is a versioned derivation of the accepted R3 harness. It preserves wrapper-only invocation, Windows PowerShell 5.1 cryptographic identity creation, deterministic npm/npx resolution, exact signer verification, CertUtil trust and teardown, create-only lifecycle/evidence publication, archive verification, failure outcomes, and final machine/repository checkpoints.

R4 changes only qualification infrastructure and living programme records. Product source is the exact committed candidate.

## R4 additions

- new contract, attempt/authority namespace, package identity/version, signer subject and evidence roots;
- exact accepted R3, Stage 3 R9 and Stage 4 R1 historical bindings;
- exact installed-runtime-configuration product-file hashes;
- pre-authority ambient configuration rejection;
- deterministic non-secret build canaries;
- generated-output and unpacked-package byte scans;
- focused custody regressions for casing, hostile ambient values, prohibited files, clean output and detected leakage;
- explicit preparation plan, gate and validation report.

The canary evidence records names and SHA-256 values, not runtime credentials. A scan failure is mandatory and cannot be downgraded.

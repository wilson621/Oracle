## Accepted outcome

Sprint 26 delivered a transient, instance-scoped Guidance delivery coordinator
owned by the Desktop Companion. It projects immutable Guidance v1 Requests from
authoritative attached Session Context, executes explicitly injected
deterministic providers and delivers validated immutable Application state to
the restricted renderer.

Detach, Context replacement, renderer replacement and recovery invalidate
obsolete Guidance. Generation ownership suppresses stale asynchronous results.
Source freshness and spoiler policy are enforced. Offline curated Guidance
remains supported and provider failure becomes an observable unavailable state.

Guidance v1 and Desktop Platform API v1 remain unchanged. Canonical Web and
Electron manifest version 1.5.0 mechanically equals both constructed runtimes.

## Permanent directive

Guidance delivery is a coordination responsibility, not a knowledge authority.
The Desktop Companion may transport validated current Guidance from
authoritative Services to presentation, but it may never create, modify or
supersede Oracle knowledge, Session state, Understanding, Missions,
Progression or any other authoritative Oracle state.

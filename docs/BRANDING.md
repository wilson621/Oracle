# Purpose

This document defines the official naming conventions and product hierarchy for Project Meta.

Visual identity, colours and design language are documented separately in **Brand-Bible.md**.

The Oracle Founding Charter governs the Oracle initiative and everyone
stewarding it. It does not silently rename the documented company, repository
or product identities below. Any corporate or legal identity change requires a
separate explicit decision.

# Official Naming

## Company

Project Meta

The software platform responsible for developing Oracle and future products.

---

## Repository

project-meta

The official source code repository.

Repository names should remain stable unless there is a deliberate organisational decision.

---

## Product

Oracle

The flagship AI intelligence system within Project Meta.

Oracle represents the complete coaching platform rather than an individual feature.

---

## Intelligence Layer

OracleBrain

OracleBrain is the intelligence orchestration layer.

Responsibilities include:

- Combining intelligence engines
- Producing recommendations
- Generating summaries
- Communicating Oracle's conclusions

OracleBrain is not a chatbot.

It is Oracle's central intelligence.

---

## Coaching Layer

Oracle Coach

Oracle Coach is the conversational coaching experience built on OracleBrain.

It transforms Oracle's intelligence into personalised coaching.

---

## Player

Operator

Every player using Oracle is known as an Operator.

The term "Operator" reinforces identity, immersion and consistency throughout the platform.

Avoid using "User" unless referring to technical implementation.

---

# Future Product Structure

Project Meta is designed to support multiple products.

Future products should sit alongside Oracle without affecting Oracle's identity.

Example

```text
Project Meta

├── Oracle
├── Product Two
├── Product Three
└── Future Products
```

Oracle should always remain an independent product rather than becoming synonymous with Project Meta itself.

---

# Naming Rules

Always use:

- Project Meta
- Oracle
- OracleBrain
- Oracle Coach
- Operator
- Oracle Session

Avoid introducing alternative terminology unless there is a deliberate branding decision.

Consistency strengthens the brand.

---

# Brand Personality

Oracle should always feel:

- Intelligent
- Calm
- Professional
- Tactical
- Analytical
- Premium
- Trustworthy

Oracle should never feel:

- Loud
- Childish
- Overly emotional
- Meme-like
- Overly playful
- Generic

---

# Final Principle

Project Meta builds software.

Oracle delivers intelligence.

Every branding decision should reinforce that distinction.

# PROJECT META BRAND BIBLE

Version 1.0

Last Updated: 7 July 2026

---

# Purpose

This document defines the visual and experiential identity of Project Meta and Oracle.

Project Meta should feel like a premium AI software platform.

Oracle should feel like an elite intelligence system for competitive gamers.

The interface should communicate intelligence, precision, confidence and evolution.

---

# Brand Structure

## Project Meta

The overall software platform.

Project Meta may eventually contain multiple products, modules or systems.

## Oracle

The flagship AI intelligence system inside Project Meta.

Oracle is the primary coaching intelligence.

## OracleBrain

The intelligence orchestration and personality layer.

## Oracle Coach

The conversational coaching experience.

## Operator

The player using Oracle.

---

# Brand Feeling

Project Meta should feel:

- Premium
- Intelligent
- Tactical
- Calm
- Futuristic
- Precise
- Trustworthy

Project Meta should not feel:

- Arcade-like
- Loud
- Cartoonish
- Generic SaaS
- Meme-driven
- Overly gamified

---

# Visual Inspiration

Oracle should feel closer to:

- Mission Control
- Military intelligence systems
- JARVIS
- F.R.I.D.A.Y.
- Bloomberg Terminal
- Tactical command software
- Premium performance dashboards

Oracle should not feel like:

- Discord
- Tracker websites
- Generic gaming overlays
- Bright esports templates
- Casual chatbot interfaces
